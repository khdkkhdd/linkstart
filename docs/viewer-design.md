# Recording viewer

Personal viewing from Tailscale devices; prioritize newest TwitCasting recordings.
Reference: Mozilla Protocol video component, https://protocol.mozilla.org/components/detail/video.html (via Component Gallery). Borrow its full-width responsive native video and default controls. Use a quiet dark background, system typography, 8px spacing increments, subtle borders, mint selection, and a flat latest-first list rather than decorative cards. Player above filters and list; no automatic playback on initial load. Mobile layout wraps filters. Resume positions are stored per browser. Completed top-level MP4s only; recording parts are excluded.
